# simple_attendence_marker
# 📋 Smart Attendance Marker

A sleek, responsive, and easy-to-use web application built with **HTML**, **JavaScript**, and **Tailwind CSS** for quickly tracking daily student attendance. Designed with a clean glass-inspired UI, it runs entirely in the browser using `localStorage` so your data persists locally without needing a backend database.

---

## ✨ Features

* **⚡ Fast Status Toggling:** Instantly switch between `✓ Present` and `✕ Absent` with a single click.
* **📊 Live Statistics Bar:** Automatically updates total student counts, present/absent breakdowns, and overall attendance percentages in real-time.
* **➕ Dynamic Student Management:** Add new students with custom Roll Numbers and Names instantly.
* **📥 CSV Export:** Download your daily attendance report as a CSV file compatible with Excel or Google Sheets.
* **🔄 Bulk Actions:** Quickly mark everyone present/absent or reset the list with dedicated control buttons.
* **💾 Local Storage Persistence:** Saves your student list and attendance state locally in your browser.
* **📱 Responsive Design:** Clean layout that looks and works great on both desktop and mobile devices.
